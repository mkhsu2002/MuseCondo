# 住戶角色暫定方向

使用者目前定調：Muse Tower 住戶暫採用**自創、可愛的外星精靈**。主對話正在提供四款視覺提案供使用者選擇，角色造型尚未定案；此分支不自行選定或批量建立住戶肖像。

- 現有二十張住家畫面是無住戶人物的原創室內圖；它們不代表已選定的外星精靈造型。
- 不使用、重繪或模仿 Muse 官方 Agent、角色、吉祥物、品牌肖像或標誌作為住戶。
- 對官方外觀的研究不等於使用批准，也不表示相關角色可隨開源程式散布。
- 未來只有在正式取得官方授權、確認實際使用與散布範圍後，才可依使用者決定替換或強化角色素材。**目前沒有取得該官方授權。**
- 本次 Codex 暫用圖像例外只處理開發素材來源，不擴張商標、角色或其他第三方權利，也不改變應用執行期 Meta-only 模型架構。

人物角色與住家環境分開保存，後續選定原創外星精靈後可獨立整合，不需改變住戶門牌、兩層路由、授權或日常內容模型。這是設計約束，並不代表人物生成或替換流程已實作。
