# Agent 形象與住所方向

狀態更新：2026-10-29。framework `0.01` 採 Agent 自由形象與場景；本文件取代早期將所有住戶固定為「星芽族」的規則。歷史示範仍可保留原角色，但不能用來限制新住戶或作為缺少 seed 時的預設生成。

## 現行契約

Agent 在獲授權、已精簡的 evidence 基礎上，分別描述：

- 住所形式 `home.form`。
- 自身形象 `home.selfImage`。
- 正在進行的活動 `home.activity`。
- 牆上或桌上的主人畫像 `home.ownerPortrait`。
- 可辨識的窗戶 `home.window` 與窗外景色 `home.view`。

物種、身體外形、材質、配色、建築與家具不固定。各描述必須引用 seed 內有效的私密 evidence ID；來源摘要、推測與想像必須按契約標記，不能把想像寫成已知事實。主人畫像預設 `imagined`；採 `identifiable` 時必須明確提供 `explicitConsent:true`。

Agent 本人須出現在住所內，正在做自己選定的事，且主人畫像與窗戶／景色能辨識。桌機 16:9 與手機 9:16 是同一住所的兩種構圖，不是兩次重新設計。這些是生成與驗收契約，不放進訪客頁面的說明文案。

公開前以當前兩張圖的 SHA-256 綁定視覺驗收收據，逐項確認本人、活動、主人畫像、窗戶及配對一致性。檔案驗證與收據有效不等於伺服器自動辨識或證明畫面內容；真實圖像仍須目視確認。

## 歷史示範：星芽族（封存方向）

早期十戶虛構原型曾採共同物種：紙感水彩／色鉛筆、梨形身體、柔和肚皮及不對稱葉狀感測鰭，再以衣著、小物與配色區分。這段只記錄示範資產的設計背景，不是 framework 的必要條件，也不要求新 Agent 使用獨立人物卡或將人物與住所分離。

歷史原型不是正式 Meta 生成或真實住戶的證據。原始提示詞、素材來源鏈與製作紀錄屬開發／受控稽核資料；正式建置排除相關歷史 manifest，不在公開頁面或 API 展示 prompt、模型 metadata 或製作流程。

## 權利邊界

自創原型不代表取得 Muse 官方角色、吉祥物、肖像或標誌授權。使用品牌與使用者授權的個別素材，不能推導成其他 Agent 或下游取得重製權。未取得明確授權的官方形象不得仿製或宣稱官方關係。
