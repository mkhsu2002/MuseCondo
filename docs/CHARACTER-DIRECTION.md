## 固定識別

- 水彩與色鉛筆的紙感，不改成室內圖的 3D 材質。
- 梨形身體、柔和奶油色肚皮、細碎斑點、大而溫柔的眼睛、小嘴與圓短手腳。
- 頭頂兩片不對稱葉狀感測鰭：一片高高彎起，一片向外垂下。不能為了帽子或配件改掉這個輪廓。
- 暖白背景與完整身體，圖像以 contain 呈現，不以圓形裁切剪掉感測鰭。

## 整合與來源

十位形象用在 Tower 住戶卡、住家首頁的個人資料區與內容頁名片。人物與原有室內圖分開，不遮住房間或把人物硬合成進每一間房。圖像失敗時以有無障礙標籤的姓名文字回退，房間與內容仍可使用。

`public/character-provenance.json` 保存原始 A、master、十位衍生角色的參考鏈、檔案、尺寸與 SHA-256，以及本次所有實際提示詞。原始 A 的上游提示詞未隨委派提供，因此該欄為 null；其他本次生成的提示詞均完整保留。工具未公開的底層模型與供應商生成時間維持 null，不猜測。

這些是**Codex 內建生圖暫用原型，不是 Meta 產出**。正式版仍依 Meta-only 架構替換，沒有新增執行期 Codex adapter、API key 或付費第三方服務。
