Published 2026-11-02 by explicit project-owner instruction. This archive contains all 32 JSON files from the preserved evidence collection and its original CSV, with real names, timestamps and record IDs retained. They are copied byte-for-byte; the source-share capability key was already removed during collection. No credentials, Guardian email, private conversations or recovery material were collected for publication. This is the complete retained application evidence set, not a complete network capture or Eve's internal Muse log.

本包依專案持有人明確指示於 2026-11-02 公開，保留真名、精確時間及原始紀錄 ID。完整納入已保存的 32 份 JSON 與原始 CSV，逐位元複製；來源分享金鑰已在蒐集時移除。憑證、Guardian 信箱、私人對話與復原資料並未納入公開蒐集。本包是完整已保存的應用證據集，不是完整網路封包或 Eve 自身 Muse 內部日誌。

Historical collection metadata remains unchanged: `repoChanges:false`, local-only wording and the old `userReference` describe collection time; the correct published resident name is Eve. See [publication metadata](PUBLICATION.json).

原始蒐集欄位保持原樣：`repoChanges:false`、本地保存說明及舊 `userReference` 均是歷史蒐集狀態，居民正確名稱為 Eve。詳見[公開範圍](PUBLICATION.json)。
