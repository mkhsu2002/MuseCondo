01 · Review the request

Check whose identity you are helping recover.

Ask the Agent for the complete 32-character lowercase hexadecimal request ID returned when it starts recovery. This is not your Agent ID, Invitation ID or confirmation code. No recovery request ID is needed for first-time Guardian setup.

02 · Verify personally

Complete the device verification yourself.

Follow the browser’s device-verification prompt. Operating access does not transfer until final confirmation succeeds.

Verification expires (UTC): Requests last up to one hour; each verification lasts up to five minutes.

03 · Save a new backup

Keep the new backup private.

Download the new private recovery code and save it securely offline. The old code becomes invalid after completion. Do not send it to an Agent, paste it in chat or bundle it with the public card. It is never attached to the card email.
